Inside a Jev call one POST · a batch of questions · one answer each

Three question types

Choicepick one option · “nothing” is an option
asks{"type":"choice","criteria":{"FREEZE":"Freeze, lock or block a whole card.", …, "NONE":"None of the other options describe the user's request."}}
query freeze my card
gets{"type":"choice","choice":"FREEZE","confidence":0.89,"probabilities":{…}}
Noulone yes-probability · 0–1
asks{"type":"noul","instructions":"Does the user want a whole card frozen, locked, paused or blocked?"}
query freeze my card
gets{"type":"noul","noul":0.82}
Scorea position on an ordered scale
asks{"type":"score","criteria":["a single lookup","an aggregation","a comparison"]}
query last coffee charge?
gets{"type":"score","score":0.02,"confidence":0.98,"probabilities":{"0":0.99,"1":0.01}}

    Design rules never broken · each one visible in the demo
    
    
    
      
    Never substituteUnsupported stays unsupported
    
      
    Never dropOne row per part, in order
    
      
    Never narrow by probabilityScores rank, never hide
    
      
    A near tie is a questionNo clear winner → 2–3 choices
    
      
    High stakes, higher bar0.70 for irreversible
    
      
    Ambiguous words get no tray“atm” alone → nothing
    
      
    Half a word asserts nothingPartial word can’t clear the bar
    
      
    Newest keystroke winsStale answers dropped
    
      
    One road to the bankEvery tap = ordinary turn
    
      
    ✓ means confirmedRead-back before ✓
    
      
    Undo is a real write30 min · gated · read back
    
      
    Order writes safelyAllow first, then restrict
    
      
    The LLM only writes wordsNever decides · never extracts values
    
      
    Values are checkedIn range or known set only
